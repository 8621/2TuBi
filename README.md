# 2TuBi

> **历史存档 / 已停止维护**
>
> 本仓库仅用于保存历史代码，不再提供功能更新、兼容性修复或运行支持。

2TuBi 是一个曾用于 t00ls 自动签到并通过 Server酱推送结果的 Go 程序。项目早期包含每日备案域名查询功能；该功能因会对 t00ls 造成额外负担而被移除。

## 历史运行环境

- Go 1.16
- 运行前需要在源码中配置 t00ls 用户名、MD5 密码、安全问题及答案，以及 Server酱 SendKey，然后自行编译运行

上述环境和配置方式仅用于说明项目历史状态，不代表当前仍可正常使用。

## 安全提示

- 原实现会将账号凭据和推送密钥直接写入源码。请勿提交、分享或公开任何真实凭据；如曾泄露，请立即更换。
- 项目依赖的站点接口和第三方服务可能已经变更或失效，继续运行可能触发账号风控、封禁或其他不可预期行为。
- 本项目已停止维护，代码未针对当前环境进行安全审计。请仅在理解风险的前提下自行检查和使用。
